📤 Panduan Upload ke Adobe Stock

Dari studio ini sampai asetmu tayang di Adobe Stock.

Generate gambar di studio ini — 8 kategori: badge, shape, background, pola, ikon, bingkai, ilustrasi flat, divider. Gunakan Paket Harian untuk 70 gambar baru setiap hari — seed tanggal membuat tiap hari selalu unik.
Pastikan pengaturan: ukuran 2048 px (syarat minimum Adobe Stock: 4 megapiksel) dan format JPG (Adobe hanya menerima JPEG untuk gambar raster, bukan PNG).
Unduh: tombol PNG/JPG per gambar (manual), Jalankan Auto-Pilot (otomatis satu per satu), atau Unduh ZIP (semua sekaligus). Nama file otomatis dibuat ≤30 karakter sesuai syarat Adobe.
Klik CSV Metadata untuk mengunduh file metadata (Filename, Title, Keywords, Category). Judul otomatis dibatasi 70 karakter tanpa koma; kolom Category diisi 8 (= Graphic Resources, kategori yang tepat untuk semua aset studio ini).
Buka contributor.stock.adobe.com → login → Uploaded Files → New → upload semua file JPG, lalu klik Upload CSV dan pilih file CSV tadi. Judul, kata kunci (25 per gambar), dan kategori langsung terisi.
Set tipe file illustration, lalu Submit for review — biasanya direview dalam 1–5 hari kerja. Jangan centang “Created Using Generative AI Tools”: gambar studio ini dibuat prosedural/deterministik (bukan AI generatif).

💡 Tips: unduh ZIP + CSV dalam format yang sama (JPG) agar nama file di CSV cocok dengan file yang diupload. Adobe Stock menolak gambar dengan artefak kompresi berat — export JPG 2048px kualitas 92 sudah cukup tajam, dan hindari teks bermerek dagang pada badge.
