📤 Panduan Upload ke Adobe Stock

Dari studio ini sampai asetmu tayang di Adobe Stock.

Generate gambar di studio ini (kategori badge, shape, background, atau pola). Gunakan Paket Harian untuk koleksi baru setiap hari — seed tanggal membuat tiap hari selalu unik.
Unduh hasilnya: tombol PNG/JPG per gambar (manual), Jalankan Auto-Pilot (otomatis satu per satu), atau Unduh ZIP (semua sekaligus).
Klik CSV Metadata untuk mengunduh file metadata (Filename, Title, Keywords, Category) yang kompatibel dengan upload massal Adobe Stock.
Buka contributor.stock.adobe.com → login → Upload → seret semua file PNG/JPG hasil generate.
Di dashboard contributor, pilih semua file → gunakan fitur import metadata via CSV (atau tempel judul & kata kunci per file). Setiap gambar di studio ini sudah membawa judul + 25 kata kunci berbahasa Inggris.
Pilih kategori yang sesuai (mis. Graphic Resources untuk badge/shape, Backgrounds/Textures untuk background), centang “illustration”, lalu Submit for review. Biasanya direview dalam 1–5 hari kerja.

💡 Tips: Adobe Stock menolak gambar dengan artefak kompresi berat — selalu export PNG 2048px untuk kualitas maksimal, dan hindari teks bermerek dagang pada badge.
